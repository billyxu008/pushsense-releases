# PushSense — downloads

Push-to-talk dictation for macOS. Hold a key, speak, release — the transcript is typed into whatever app has focus. Speech recognition runs entirely on your Mac with whisper.cpp: no account, no subscription, no audio ever leaves your machine.

**Free to download.** This repository holds the signed, notarized builds only; the source code is private.

- **Download the latest version:** [Releases](https://github.com/billyxu008/pushsense-releases/releases/latest)
- **Product page:** https://billyxu.dev/pushsense/
- **Bug reports and feature requests:** [Issues](https://github.com/billyxu008/pushsense-releases/issues)

Requirements: macOS 13 or later, Apple Silicon.
